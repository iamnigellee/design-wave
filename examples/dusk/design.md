## 1. Brand & Soul

**Why.** Treatment culture lies. Meditation apps tell the insomniac at 2 a.m.
that everything will be okay. It won't — not tonight. Dusk doesn't fix
insomnia. It sits in it with the user.

**Three adjectives.** 克制 · 安静 · 微苦 — restrained · quiet · faintly bitter.

**Use moment.** Urban professional, 30s, lying in bed at 2:30 a.m., can't
sleep, scrolling the phone, physically exhausted but mentally wired. Portrait
single-hand, iPhone, lights off.

**Cultural coordinate.** Nordic minimal × 東亞 wabi-sabi × cyber late-night —
not American wellness.

**Differentiator.** Other meditation apps lower your anxiety with "it'll be
okay". Dusk sits in it with you without pretending.

**Psychological journey.**

1. **First open** — "Oh. This one doesn't talk down to me."
2. **Session** — "There's nothing being sold. Just the dark and a voice."
3. **Post-session** — "I'm not fixed, but I was accompanied for a while."
4. **Return** — "It's there when the light doesn't work."

## 2. References

### Positive

- **Sigur Rós album artwork** — cold, restrained, negative space, natural
  grain, no celebrity of ornament
- **Her (2013) film grade, colder** — warm melancholy pushed toward cool; the
  light after midnight, not dusk evening
- **一杯冷掉的黑咖啡** (a cup of cold black coffee) — the metaphor anchor:
  still bitter, no longer hot, honest

### Anti-references (three tiers)

| Tier | Forbidden | Why |
|---|---|---|
| hue | Calm-class pastel gradient greens, Headspace sunrise orange, startup purple (#7C3AED family), "business night-mode" deep navy | wellness-category clichés; promise of warmth Dusk refuses to make |
| material | elevation shadows of any kind, gradient chrome, subtle sheen, glassmorphism, >4px radius, emoji illustrations | all forms of "cheerful material"; contradicts restrained brand |
| copy | "Great job!", "You got this", "Breathe in — you're doing amazing", "Untitled" empty states, any emoji in UI | treatment-culture voice Dusk was built to refuse |

Copy-tier anti-references cannot be enforced by Claude Design's schema — they
are ingested as `drop-silent`. See `§ 10. Voice & Tone` below and
`upload-checklist.md § schema-projection-report` for fallback.

### Taboos (absolute — violations are bugs, not preferences)

- **No shadow, anywhere, ever.** Elevation communicated by 1px border + 2–5%
  luminance step between surfaces.
- **No spinner on loading states.** Three dots `···` instead. Spinners are
  "too busy" at 2 a.m.
- **No "Great job" or equivalent post-session affirmation.** Session ends in
  silence. Maybe a timestamp. Nothing more.

## 3. Positive Constraints

User-asserted rules enforced by `scripts/token-lint.py`. Not overrideable
within a run.

### `accent-as-signal-only`

- **Rule.** Signal color (`signal.flax`) appears only in: primary CTA default
  state, focus ring, error state border, selected state indicator. Never in
  decoration, hero typography, illustration, or background.
- **Scope.** `components.*.variants.*.default.bg`,
  `components.*.variants.*.focus.*`, `components.*.variants.*.error.*`
- **Enforcement.** Manual review — semantic rule cannot be fully automated.
- **Rationale.** Color is a signal, not a decoration. The eye should only
  see flax when the UI needs attention. Any additional use dilutes the
  signal.

### `weights-restricted`

- **Rule.** Typography weights drawn only from `{400, 500}`. Weights 600 / 700 /
  900 forbidden.
- **Scope.** `typography.scale.*.weight`
- **Enforcement.** `scripts/token-lint.py --positive weights-restricted`
- **Rationale.** Bold type speaks at 2 a.m. At that hour nothing should speak
  loudly.

### `material-policy`

- **Rule.** Materials `noise`, `chrome`, `liquid`, `gloss` are blacklisted.
  Surface finish is flat matte.
- **Scope.** `material.*`
- **Enforcement.** `scripts/token-lint.py --positive material-policy`
- **Rationale.** Night does not glisten. No sheen contradicts the cold-coffee
  reference.

## 4. Foundations

### 4.1 Color

Dark-primary. The default mode IS dark; light mode is a derivative, not the
reverse. Palette centered on warm-undertone neutrals (hue ≈ 30°–40°, sat
≈ 6%–33%) with one signal color (`flax` / #A89680, sat 15%) as the only
accent.

The palette is a ladder with eleven stops in `neutral.*`. The three darkest
stops (950 / 900 / 800) are deliberately close-stepped (≈ 3% L* between
adjacent) to create subtle surface layering without introducing shadow.

Full token map in `design.tokens.yaml § color`.

### 4.2 Contrast Tiers

All three tiers enforced at AA. No elevation to AAA; no relaxation to free.

| Tier | Required | Scope globs |
|---|---|---|
| text | AA (≥ 4.5:1 body, ≥ 3.0:1 large) | `text.*`, `components.*.label`, `components.*.value` |
| ui | AA (≥ 3.0:1 non-text) | `border.*`, `components.*.focus.ring` |
| decoration | AA | `backgrounds.pattern.*` |

Rationale: Dusk uses no decorative layer that hides information. A uniform
AA floor is sufficient and brand-coherent with the "no ornamentation" stance.

### 4.3 Typography

Single family, two weights.

- **Family.** `Söhne, Inter, -apple-system, BlinkMacSystemFont, sans-serif`.
- **Weights.** 400 (body / subtle) and 500 (headings / emphasis) only.
  Bolder weights forbidden by `weights-restricted` positive constraint.
- **Scale.** Six stops — `display 40 / h1 28 / h2 18 / body 16 / small 14 /
  micro 12`. Display at 40px (not 32px — 32 read as "announcement" on 375
  viewport; bumped during preview gate).

Full scale in `design.tokens.yaml § typography.scale`.

### 4.4 Spacing & Layout

Explicit array: `[0, 4, 8, 12, 16, 24, 32, 48, 64, 96]`. Mobile-first
portrait-single-hand. Container max 640px. Grid standard 12 columns.

Three named pages with density deltas against base:

- `home` — full-bleed stack on narrative-calm copy
- `session` — sparse density; one focal element per screen
- `journal` — default density; archive-readable

### 4.5 Radius · Border · Elevation

- **Radius.** Global default 2px. Named stops: `none 0 / sm 2 / md 4`.
  Nothing above 4px permitted (round corners carry warmth Dusk refuses).
- **Border.** 1px hairline default; 2px thick for focus ring. Solid style.
- **Shadow.** Forbidden globally. Taboo-level. Elevation communicated by:
  1. 1px border on raised surfaces
  2. 2–5% luminance step between surfaces (canvas → surface → elevated)

### 4.6 Motion

One timing function. Slow duration. No bounces, no drama.

- **Duration.** `fast 200ms / base 400ms / slow 600ms / dramatic 600ms`.
  Dramatic equals slow — there is no dramatic tier.
- **Timing.** `cubic-bezier(0.32, 0.72, 0.24, 1)` — one value, applied
  universally.
- **Reduced motion.** Strategy: `remove` (not reduce). Respects user
  preference absolutely.

### 4.7 Material

Declared flat matte. All textures forbidden by `material-policy`.

```yaml
material.matte: {render: flat}
```

No noise. No chrome. No liquid. No gloss. No composite. Dusk is a surface
without surface.

### 4.8 Iconography

Outline-style SVG, stroke 1.5px, 20×20 viewBox. Sharp corners. No filled
glyphs except the selected-state indicator (a 2px bar, not an icon).

## 5. Semantic Tokens

Every component references semantic tokens, never palette stops directly.

```
bg.canvas       → neutral.900  (the default surface)
bg.surface      → neutral.950  (raised: cards, dialogs — note: darker, not lighter)
bg.elevated     → neutral.800  (hover / active state)
fg.primary      → neutral.50   (body text)
fg.secondary    → neutral.300  (subtitles, less important)
fg.muted        → neutral.400  (hints, metadata)
border.subtle   → neutral.800
border.strong   → neutral.700
accent.primary  → signal.flax
```

Note the counter-intuitive mapping: `bg.surface` is *darker* than `bg.canvas`
(950 vs 900). Cards recede into the night, not out of it.

## 6. Components

Full specs in `design.tokens.yaml § components`. Summary:

- **Button** — primary (fg on canvas — inverted for CTA weight) + secondary
  (transparent with border). Loading content: `dots`, never spinner.
- **Input** — `form-5state`. Default has subtle background fill
  (`bg.elevated`) for affordance; border hairline on all sides.
- **Card** — hover changes border color only, never elevates.
- **nav-item** — `label-always-visible: true`; icon + text permanent.
  Selected indicator: 2px bar on the left (not underline).
- **list-row** — line separator, 44px min-height for touch.
- **form-row** — line separator, label + value justified, no background.

### Do & Don't

- ✅ Card hover: border `subtle → strong`.
  ❌ Card hover: add shadow. (Shadows forbidden.)
- ✅ Button loading: text replaced by `···`.
  ❌ Button loading: spinning circle.
- ✅ nav-item selected: 2px flax bar on left.
  ❌ nav-item selected: fill background with flax.
  ("Signal, not decoration" — flax bar is a signal; flax fill is decoration.)

## 7. Patterns

- **Empty state.** Three dots `···` centered. No copy. No illustration.
- **Loading.** Same three dots on top of whatever is loading. No progress bar.
- **Error.** 1px flax-adjacent border + `fg.muted` hint text below. No banner,
  no modal, no toast.
- **Confirm.** Two buttons stacked vertically, full-width. No side-by-side
  Accept / Cancel.

## 8. Accessibility

- **Contrast.** All fg/bg combinations AA. Minimum observed: `fg.muted` on
  `bg.canvas` = 4.8:1 (passes AA body).
- **Focus ring.** 2px solid `signal.flax`, offset 2px. Visible on all
  interactive elements. Never relies on color alone — offset creates a
  geometric change detectable independent of hue.
- **Reduced motion.** Strategy `remove`: transitions removed entirely when
  user prefers reduced motion. Functionality preserved.
- **Touch targets.** list-row `min-height: 44` guarantees tap area even at
  tight density.

## 9. Theming

### Default mode

**dark.** Dusk's use moment is 2 a.m. in bed. Light mode is derivative, not
primary. Samples render dark-first.

### Dark mode

All semantic tokens have explicit `color.dark.*` values — no `auto-invert`.
The dark map is identical to the non-dark map because dark *is* the default.

### Light mode

Declared derivative; not emitted in v1.0. Reserved for v1.1 (see Roadmap).
When added, will be an explicit inverse, not a runtime negation.

## 10. Voice & Tone

This section is `drop-silent` under Claude Design's schema — voice / tone
does not have a schema surface in the 4-category ingestion. The team
enforces it manually during copy review.

### Stance

Dusk speaks in second-person present, declarative. Short sentences. Never
exhortative. Never celebratory. Never apologetic.

### Forbidden

- Any affirmation ("Great job", "Well done", "You did it")
- Any emoji
- Any exclamation point
- Any "!" or "?" in UI labels (copy body may use as needed)
- Any placeholder phrasing ("Untitled", "Enter your name here")
- Treatment phrases ("breathe in", "relax", "let it go", "release")

### Required

- Timestamps on all journal entries (date + time, minute precision)
- Specific time references ("3:14 a.m.", not "late at night")
- Neutral verbs ("start", "stop", "return", "leave")

### Sample microcopy

```
Session (not: "Start Session")
End (not: "Finish", not: "Done")
Sign out (not: "See you tomorrow!")
3:14 a.m. (not: "Now")
```

## 11. Internationalization

Single-locale product in v1.0 (English). Chinese-simplified planned for v1.2
(see Roadmap). No RTL considered — Arabic and Hebrew deferred to v2.

## 12. Out-of-Schema Extensions

Claude Design's 4-category schema will silently drop these bundle fields at
upload. Each has a fallback recipe in `upload-checklist.md §
schema-projection-report`.

- **`accent-as-signal-only` positive constraint** — not a schema field;
  enforced by manual review + documented in § 3 above.
- **`shadow.policy: forbidden`** — schema has a shadow scale field but no
  "forbidden" policy. Fallback: explicit `shadow: none` on every component
  state; the absence itself communicates the rule downstream.
- **`button.loading.content: dots`** — schema supports a `loading` state but
  not a content subtype. Fallback: component-level implementation note; UI
  engineers render dots explicitly.
- **`nav-item.selected-indicator.style: bar` + `position: left`** — schema
  typically assumes bottom underline. Fallback: explicit CSS in sample
  rendering + terminology-map note.
- **`voice-and-tone` anti-references** — schema has no voice surface.
  Fallback: documented in § 10 above; human writers enforce.

## 15. Roadmap & Reserved Changes

### Roadmap

- **v1.1** — explicit light-mode token set as inverse of dark (not
  auto-invert). Triggered by: user feedback on bright-daylight usage.
- **v1.2** — zh-Hans locale. Triggered by: first non-English user cluster.
- **v2.0** — expanded icon set (currently minimal). Triggered by: feature
  expansion beyond meditation + journal.

### Reserved changes (may mutate within v1.0)

- **`color.signal.flax`** — currently `#A89680` (flax). User reserved the
  right to switch to a "deep cold teal" within two weeks post-launch if
  flax reads too warm in user testing. Decision deadline: v1.0 + 14 days.
