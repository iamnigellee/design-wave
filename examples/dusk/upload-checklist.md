### Why neutral-scale warns (not fails)

The dark stops 950 / 900 / 800 step by ~3% L* — below the script's default
5% floor. **Intentional.** The close stepping is how Dusk communicates
elevation without shadow: canvas (900) → surface (950, slightly darker) →
elevated (800, slightly lighter). The perceptual deltas are smaller than
the script's threshold, but that's the brand point.

The warn is logged for reviewer visibility rather than suppressed.

## Post-upload manual actions

After Claude Design publishes, perform these checks manually (none are
automated by this bundle):

🔴 **Signal color placement audit.** Spot-check 5 generated pages.
  Confirm `signal.flax #A89680` appears only in primary CTA, focus
  ring, error border, and selected indicator. If it appears in
  decoration or body text, the `accent-as-signal-only` rule drifted —
  add it as a test prompt and re-iterate.

🔴 **Shadow audit.** Spot-check 5 generated pages. Zero box-shadow
  declarations should be present. If any appear, add "no shadow" to
  the next generation prompt explicitly and re-iterate.

🔴 **Loading-state audit.** Generate a page with a loading state
  (e.g., "为 Dusk 设计一个加载中的卡片"). Verify the generated state
  shows dots, not a spinner. If a spinner is generated, add "loading
  shows three dots, never a spinner" as explicit prompt context.

🔴 **Voice & tone audit.** Generate any copy-heavy screen (empty state,
  onboarding, error). Confirm no affirmations ("Great job!") or
  exclamation points appear. Copy-tier rules are schema-silent and will
  need recurring manual review.
