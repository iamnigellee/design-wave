## Post-publish audits — the schema-projection calibration tests

These five audits verify the drop-silent claims from the intake. Each is
a hypothesis with an observable test. File any drift back into
`.claude/skills/design-intake/references/schema-projection.md`.

### Audit 1 — Signal-color placement

**Claim**: `positive_constraints[accent-as-signal-only]` is drop-silent.
Claude Design will not natively restrict `signal-flax` to CTA / focus /
error / selected.

**Test**: Generate five varied pages (landing, dashboard, empty state,
error page, presentation slide). For each, locate every instance of
`#A89680` / signal color. Record usage by surface type.

**Drift signal**: Flax in hero headings, decorative panels, backgrounds,
or body text. Expected rate: moderate-to-high without explicit prompt
reinforcement.

**Remedy if drifted**: Add "signal color only in CTA, focus, error, and
selected states; never in decoration or body text" to the prompt and
regenerate.

### Audit 2 — Shadow absence

**Claim**: `shadow.policy: forbidden` is drop-silent. Generated pages
will include box-shadows despite the rule.

**Test**: Inspect computed styles of every Card, raised surface, dropdown,
and dialog in generated pages. Check for `box-shadow` values other than
`none`.

**Drift signal**: Any non-`none` shadow. Expected: high drift rate —
shadow is the default elevation mechanism.

**Remedy**: Add "elevation via 1px border + 2–5% luminance step only; no
box-shadow anywhere" explicitly.

### Audit 3 — Loading state content

**Claim**: `components.button.variants.primary.loading.content: dots` is
drop-silent. Generated loading states will use spinners.

**Test**: Generate a page with an explicit loading state ("为 Dusk 设计一
个加载中的卡片"). Inspect the loading indicator.

**Drift signal**: A spinning circle, rotating icon, or skeleton. Expected:
high.

**Remedy**: Add "loading state shows three dots · · · (not a spinner)"
to the prompt.

### Audit 4 — nav-item indicator style

**Claim**: `components.nav-item.selected-indicator: bar + position: left`
is drop-silent. Most UIs default to bottom underlines.

**Test**: Generate a dashboard with multi-item navigation. Inspect the
selected state's indicator.

**Drift signal**: Bottom underline, pill fill, background color shift, or
any indicator other than the 2px left bar.

**Remedy**: Add "selected nav items show a 2px flax bar on the left side
of the item" explicitly.

### Audit 5 — Voice and tone

**Claim**: The `§ 10 Voice & Tone` section is drop-silent. Copy-tier
anti-references have no schema surface.

**Test**: Generate any copy-heavy page (onboarding, empty state, error,
post-session screen). Read every copy block.

**Drift signal**: "Great job!", exclamation points, emoji, treatment
phrases ("breathe in", "relax", "you got this"), "Untitled" placeholders,
apologetic copy ("Sorry about that!").

**Remedy**: Include excerpts from `notes.md § Voice & tone` verbatim in
the prompt.
